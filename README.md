# Lineage Imperative live view

The live view of the Lineage Imperative v3 framework and the work running on it, as shown at
https://lineageimperative.org/live.

This repository is generated automatically. Every ten minutes a filtered snapshot of the project's work in progress
is published here and served by GitHub Pages: the structure of the framework, which parts are online, and the
progress of the simulations running on it. It carries progress and structure only. Results stay sealed until they
have been reviewed, so nothing here reports an outcome.

Each update replaces the previous one, so the history holds a single commit.
